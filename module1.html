Module 1 - ICT Department

This page provides learning resources, practical assessment records, trainer e-portfolio information, observation checklists and student portfolio records for learners undertaking Module 1 in the ICT Department.

Module 1 focuses on fundamental computer operation skills, computer hardware, software and essential ICT competencies.

Learners are expected to demonstrate competent use of computers, safe working practices, proper handling of computer equipment, use of operating systems, application software and basic computer maintenance procedures.

Module 1 Learning Areas

Computer Operations

This unit covers practical computer operation skills including starting and shutting down computers, using operating systems, managing files and folders, using application software, printing and maintaining a productive computer working environment.

View Learning Plan

Computer Essentials

This unit introduces essential computer concepts including computer hardware, software, input and output devices, storage devices, operating systems, computer security, maintenance and safe use of ICT equipment.
