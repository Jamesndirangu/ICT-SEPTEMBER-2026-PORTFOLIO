Module 2 - ICT Department

This page provides learning resources, practical assessment records, trainer e-portfolio information, observation checklists and student portfolio records for learners undertaking Module 2 in the ICT Department.

Module 2 focuses on computer repair and maintenance as well as computer network setup skills.

Learners are expected to demonstrate safe working practices, correct use of computer repair tools, troubleshooting techniques, network installation procedures and quality technical workmanship.

Module 2 Learning Areas

Computer Repair and Maintenance

Practical skills in identifying computer hardware faults, troubleshooting computer systems, replacing defective components, performing preventive maintenance and testing computer systems after repair.

View Learning Plan

Computer Network Setup

Practical installation and configuration of computer networks, including network devices, network cables, IP addressing, workstations, network testing and basic network troubleshooting.

View Learning Plan
