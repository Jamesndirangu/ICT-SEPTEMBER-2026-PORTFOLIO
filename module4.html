Module 4 ICT Units

Unit 1: Manage Computerized Database Systems

Development and management of computerized database systems, including database concepts, database design, tables, relationships, queries, forms, reports, data manipulation, security, backup and maintenance of databases.

Unit 2: Apply Computer Programming Principles

Application of programming principles including algorithms, flowcharts, programming constructs, variables, data types, operators, control structures, functions, arrays, debugging and development of computer programs using appropriate programming languages.

Unit 3: Apply Entrepreneurial Skills

Application of entrepreneurial knowledge and skills in identifying business opportunities, developing business ideas, preparing business plans, managing resources, marketing, financial management and operating ICT-related enterprises.

Unit 4: Apply Communication Skills

Application of effective communication skills in the workplace through verbal, non-verbal and written communication, active listening, presentation skills, report writing, interpersonal communication and use of appropriate communication channels.
